
# TravelMate - Online Travel Planner

TravelMate is a responsive travel planning website built using
HTML, CSS and JavaScript.

## Features

- Search popular travel destinations
- View destination cards and estimated budgets
- Create a basic day-wise travel itinerary
- Submit a demo booking request
- Responsive layout for mobile and desktop

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open index.html in your browser.
4. For local development, use the VS Code Live Server extension.

## Important Note

This version is a frontend demonstration.
It does not provide live flight or hotel availability,
real reservations, online payments, or database storage.
